## The destination, and the one hard rule

Land on `main`, then clean up for a public alpha.

**Landing is a joint act. Never do it alone** — Michelle asked to be
there for it. That is not a preference.

Its prerequisites are not features: `.githooks` **does not exist on
`main`**, so the commit gates cannot be armed without planting a relative
path that resolves to nothing for anything branching off it; several
corpus findings cite `now/docs/` files that live only on lane branches
(`toolbox-and-gworld.md`, `deriving-a-drawn-procedure.md`,
`charcoal-strike.md`, `fidelity-sweep-spec.md`, and the fragile
`qemu-memory-oracle.md`, which sits on a checkpoint ref and no named
branch at all); and the arc-to-main merge has never been attempted in
that direction.

**Breadth is not the enemy of landing.** Nearly everything that made the
product better came from work that looked tangential when it started.

## Traps that cost this session real time

Each of these produced a wrong measurement that somebody believed:

- **The planes arm as a RESULT of the first `scene.request`**, so a
  first-on-connection capture returns every role `unknown` and is
  indistinguishable from a real defect. **Discard a warm-up scene.**
- **A process acquires an anchor slot only while it is itself pumping
  events with the plane armed.** Front or `cycle` each target, or you
  measure the anchor defect and call it a render defect.
- **The content plane must be armed** or interiors report empty — a
  property of the rig, not the product.
- **`os91-runner.qcow2` has been dirty since 19 July** (unmounted bit
  clear), so every clone pays a Disk First Aid pass. Known; needs a quiet
  machine.
- **`tools/lane-ports reclaim` deletes the run directory, screendumps
  included.** Copy evidence out first.
- **`scripts/build-guests` skips silently without `.env.lab`** — now
  placed at the common root, but confirm the artefact reads as
  *"executable (RISC System/6000 V3.1)"* rather than trusting "ok".
- **QMP `quit` is a power cut.** Five lanes did it in one night.

## The shape of what was found

Most of what looked broken was not. `as Buttons` worked — the plane
could not report it. Mouse was addressable — it lacked names.
Appearance's control cap was never reached. Ten windows versus one was
the same machine, differently driven. **Four apparent defects, four
instruments lying**, and the renderer was mostly right and under-fed.

The honesty rule kept generalising past pixels: a menu that refuses
rather than hijacks, a process that says `unknown` rather than `empty`,
a drag that snaps back rather than guessing home, a verb that admits it
dispatched without landing, a control kind that stays unknown rather
than inferred.

And the sharpest single measurement: **the window rect decomposed to a
content top of 68 against an actual 70, so the render was two pixels out
on every control in that window** — found by making one reader
authoritative, not by looking harder at a picture.
