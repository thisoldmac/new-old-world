## Nine things a fresh session gets wrong

Every one of these cost real time today.

- **`main` is not a base to branch from.** ~1100 commits behind, no
  `mirror/` tree. Branch off `claude/019-integration-7`.
- **The commit hooks are dead in every worktree.** `core.hooksPath`
  points at a directory that does not exist, because the shared checkout
  is parked on `claude/mirror-subproject`, which predates `.githooks`.
  Commit with `git -c core.hooksPath=.githooks commit`. **Do not run
  `hooks-doctor --fix`** — it rewrites config ~258 worktrees share, and
  it cannot fix the branch half anyway.
- **One worktree per lane, always.** `git worktree add <path> -b <branch>`.
  A shared worktree checked out under a running lane caused **four**
  distinct failures today, including a commit whose message never
  mentioned that it reverted its own predecessor across seven files.
- **`spin-up-ppc`'s base used to be a 19-July image.** Fixed, and every
  run now prints which base it cloned. Clone `now-mirror-stage.qcow2`
  explicitly and read the line.
- **Never QMP `quit`.** Use `tools/shutdown-guest.py --wire` — the Finder
  route, the only one measured to leave a clean HFS volume. A power cut
  is the root of this project's dirty-image class.
- **Never kill by port.** `lsof` matches QEMU itself; that is how a VM
  gets destroyed by someone aiming at an app.
- **Isolate a host with BOTH `NOW_PREFS_SUFFIX` and
  `NOW_AGENT_SOCKET_SUFFIX`**, and note there are **two preference
  domains with different names** (`dev.newoldworld.now.settings.<suffix>`
  and `dev.newoldworld.now.<suffix>`). Seeding the wrong one is silent
  and the app looks healthy on the wrong port.
- **Ports 16728/16729 and block 590–599 are Michelle's.** Structurally
  reserved in `tools/lane-ports`; do not force into them.
- **A test watched to fail against ONE mutation is not watched to fail.**
  Two render guards passed the exact mutation they claimed to catch.
  Confirm the mutation built and the test ran.

## The recovery procedure

1. `git -C <checkout> log --oneline -1 claude/019-integration-7` — confirm
   the head.
2. For every `claude/019-*` branch: is it an ancestor of integration-7?
   If not, how many commits ahead, and is its worktree dirty?
3. **Read `docs/arc-triggers.conf` and act on the locked condition.** Do
   not re-decide it.
4. Merge only clean **and** green. Resolve conflicts by **reading** —
   keep-both has twice produced parsing-but-broken code here (six
   duplicate Python `def`s; a docs entry gutted by keeping a newer
   heading and dropping an older body).
5. **Re-derive `docs/contract-coverage.md` at the merge**, with its own
   grep commands. A clean textual merge of a derived table is no evidence
   at all.
6. `scripts/test-all`, `GATE_EXIT` read from the artefact. Host gate
   twice, full logs, **never piped through `grep`**.

## Cleaning up a machine full of strangers

Several VMs and host apps may be running. **Do not assume any of them are
yours.**

- List: `pgrep -fl qemu-system-ppc` and `pgrep -fl 'New Old World'`.
- **Michelle's stack is whatever holds 16728/16729.** Leave it.
- Stop a guest with `tools/shutdown-guest.py --wire` against its
  `qmp.sock`. Quit a host app **by path**.
- Copy evidence out of a run directory **before** `tools/lane-ports
  reclaim` — it deletes them.
- **Do not `kill` by pattern.** Round 6 voided one of its own gate runs
  because a `kill` loop matching the app path killed processes the gate's
  own tests had launched.

## What this arc would want said

The recurring finding, twelve instances across five kinds, is that **an
instrument's normal mode of operation is often the one condition under
which the defect cannot appear.** A green you did not watch fail is not a
green. If you inherit this and something reads clean, ask what it would
have looked like broken — that question has been worth more than any fix
here.
