## Where you start

**Branch off `claude/gworld-interior-host-render-98ddd5`**, not `main`.
Nothing merges to `main` until the Mirror work is proven stable — still
a standing decision, not a detail.

    git -C /Users/michelle/Lab/Code/timbottu/now worktree add \
        -b <ns>/<slug> <path> claude/gworld-interior-host-render-98ddd5

`scripts/test-all` is **four stages** (native → MirrorKit → guest
cross-builds → host). The host and MirrorKit stages each run their suite
**twice — once with `NOW_MIRROR_ASSETS=none`** — so the degradation path
is watched rather than assumed. Expect it to take several minutes; the
host stage alone builds two Xcode configurations after two `swift test`
passes.

**The asset pack lives OUTSIDE git.**
`~/Lab/Assets/now-mirror-assets/pack-2026-08-06` — 1,160 files with a
`.sha256` beside it, regenerated by `tools/extract-assets-offline`
straight off a disk image with no VM in the loop. It was moved out
deliberately: it is a *dependency*, not repository content, and the
argument and the resolution order are
[asset-pack.md](../asset-pack.md). Two consequences a newcomer meets
immediately — a machine without the pack sees VISIBLE skips rather than
failures, and `NOW_REQUIRE_ASSET_PACK` turns those skips back into
failures on a machine that ought to have it.

Removing the pack from git is a stopgap, not the answer.
[Plan 017](2026-08-06-017-feat-assets-from-the-connected-guest-plan.md)
is the answer: NOW extracts a machine's own assets **from the machine it
is connected to**, which is both the product shape and the more correct
one — a per-machine pack is right for each machine by construction,
where one shared pack cannot be right for both a 68K PowerBook and an
emulated G4. It is unstarted.

## What works now that did not this morning

- **Interiors compose.** A window's real content — text at true pens,
  primitives, list rows — is captured from the offscreen world that built
  it and re-homed into the window. Finder icon/list/button views, Date &
  Time, Memory, NOW's own Workshop, Sherlock 2.
- **Worlds are hooked at BIRTH**, by a resident 68K patch on the
  QDExtensions trap (`$AB1D`), installed at the armed pass in the armed
  process's own context. This is what reaches applications whose worlds
  are created, drawn, blitted and disposed inside one event pass — the
  sight-then-chase route hooked 0 of 8 on Sherlock; the patch reports
  77 born / 77 died / 0 missed.
- **The Appearance path is the big one.** Date & Time imports no
  `NewGWorld` at all, yet reports 286 worlds born — AppearanceLib creates
  them on its behalf, and the patch catches the TRAP regardless of
  caller. Any Appearance-themed application is therefore reachable,
  which is most of Mac OS 9's own interface.
- **The join nests.** Sherlock composites two levels deep (list → interior
  world → window), and destination port ORIGINS are part of the
  translation.
- **Assets are extracted offline**, 914 per-app icons and 127 system
  icons, with Platinum's 21 accent ramps measured from the theme file.
- **Desktop items survive**, roster failures name the guest's own reason,
  and MirrorKit's suite is in the gate.
- **Invert draws, and a region can say whether its box is its shape.**
  The 34 skipped INVERT ops are drawn — invert is how classic Mac shows
  selection, carets and pressed states, so this is the difference
  between a mirror and an unselected photograph of one. The region gap
  had the opposite cause and is recorded as such: the guest now sends a
  shape word, so a region drawn as its bounding box is drawn that way
  **knowingly**, with pixel gates for both.
- **A file type reaches the atlas as a type.** `OSADoScript` answers in
  AppleScript source form, so every desktop icon carried
  `type: "«cla"` and all 914 pack lookups missed — the pack landed and
  the desktop still drew generic glyphs, which read as an asset-pipeline
  failure and was not one. Fixed (`524310e8`).

## The lesson that outranks the features

**Every real defect found today was invisible to a green test suite and
visible the moment something was compared against the machine.**

- A QuickDraw clip is port-local and moves with the origin; the replay
  froze clips into fixed host-space rects. Fifteen of Sherlock's sixteen
  channel cells were in the stream, at correct coordinates, drawing
  nothing.
- The join ignored the destination's origin, so Sherlock's volume row
  rendered at the window's top-left instead of inside its list.
- `osaErr` was parsed, matched, and discarded one line before it could be
  reported — five different failures printed one sentence.
- Desktop items were read correctly by the guest and discarded by the
  host one poll later.
- Control panels rendered every themed field as "Bitmap unavailable",
  which was a false claim of missing data.
- **Seven text-fidelity tests had a hidden dependency on the asset
  pack**, and nothing could see it until two green branches merged: one
  branch added the pack-absent pass, the other added the tests, and
  neither tree could run the other's half. On the merged tree it
  surfaced as eighteen failures saying "the renderer is broken" when
  they meant "the dependency is absent" (`d18ab259`). This one is the
  same lesson from a different direction — the comparison that found it
  was not against the machine but against a tree that had one thing
  taken away.

Our tests assert WHICH facts crossed. They were blind to WHERE things
landed and WHY things failed. **Compare a render against a guest
screendump before believing it.** `panel-recapture.py`-derived tooling
takes both in one run; screendumps live beside the renders.

## Traps, each one paid for today

- **A busy anchor port makes `scripts/spin-up-ppc` REFUSE, and your wire
  listener is then answered by another session's guest.** That voided two
  findings. Verify ports free with `lsof` FIRST, and use
  `tools/gwprobe.py --expect-build auto`, which reads this checkout's
  build hash and refuses a foreign guest. The tells to watch for: an
  identical build stamp across two supposedly fresh boots, a `psn` from a
  previous run, an empty `/private/tmp/nowvm-*` with no `qemu.pid`.
- **A probe is not the app.** A python driver speaking `scene.request`
  directly never runs the host's icon enrichment, so it cannot show
  desktop items either way. A "reconfirmation" written from one was void
  as evidence — and happened to be true by luck, which is worse than
  being wrong loudly.
- **`HostMachineGuardTests` fails when anything else holds port 5250.**
  That is the guard working, not a regression. Verify with
  `swift test --skip HostMachineGuardTests`; never weaken it.
- **A fresh agent worktree has no `.env.lab`**, so `scripts/build-guests`
  skips silently and "test-all green" then EXCLUDES the guest
  cross-builds. Copy it from a sibling worktree if you touch guest code.
- **The ring is the limit under load.** ~12 KB/s into 64 KiB is ~5 s of
  headroom; a hooked Sherlock lost 114018 bytes in one settle and its
  interior text with it. A cycle now drains up to 12 pages while the
  guest reports `more`. If an application beats that, reopen the ring
  decision WITH numbers rather than tuning the knob.

## What the perf thread brought (merged `f6833b34`)

Its own handoff is
[mirror-state-of-play-2026-08-06.md](../mirror-state-of-play-2026-08-06.md);
this is only the part that changes how you work in this tree.

- **The act wait pumps the wire, and one act at a time is enforced.** An
  act nobody takes used to hold the connection off for ~10 s, and every
  scene request in that window reported the act's duration as its own —
  an act refused after 6.6 s and a scene answered in 6634 ms were **one
  event seen from both ends**. Re-measured after: the act still costs
  its whole deadline (5.07 s — the machine still will not take it) and
  **80 scene requests were answered during it, median 65 ms**.
- **That cost a safety argument, deliberately, with Michelle's
  approval.** Pumping inside an armed window is exactly the re-entrancy
  the no-hijack work exists to prevent. What stands in its place is
  narrower: a one-act-at-a-time interlock refusing a second act with
  `act-busy` before it can write a field, watched firing on a machine.
  It guards the act cell and nothing else — scene walks, census and file
  transfers now run while a trap patch is live in every process, and
  nothing has measured whether that is safe. **The signature if it bites
  is an act that failed and a scene that moved anyway.**
- **Stall attribution.** `decode_ms` never measured decoding; splitting
  the bracket named the culprit as the visibility census, ~96% of it,
  paid every cycle for state that changes only when a process starts,
  quits, hides or shows. `decode_ms` median 353 ms → 16 ms, whole cycle
  364 ms → 25 ms, a cycle in which a Finder window opened 1,936 ms →
  26 ms, across 258 cycles all `outcome=ok`.
- **Acts stop binding when the host's cycle runs long** — the anchor
  plane's OWNER lease is 10 s and only a `scene.request` renewed it.
  Renewal now rides any inbound host frame. This is why plan 015's G1
  drain pacing was written additively; that reason is spent now.
- **`wirestat` is a verb that CHANGES the machine's scheduling**, not
  just a diagnostic — `wirestat wake off` disables the Open Transport
  wake notifier from either face without a rebuild. Worth knowing before
  a metal pass, because the notifier runs at interrupt time where a
  mistake is a crash rather than a slow answer.

All of it is emulator-only.

KEEPING BOTH sides — that file is corrected by appending.

## Known-open, with the evidence

- **Sherlock's `Custom…` popup is absent**, unexplained. The
  *magnifier* half of this line is explained and fixed: it was a 48×48
  blit being classified as a document icon (`071c3d25`).
- **No capture in the corpus has a selected list row.** Changing the
  selection colour altered no render, and forcing it to magenta as a
  control also altered nothing. Selection rendering is untested by
  anything we own.
- **Icon identity is unsolved.** Icons arrive as bits with no identity;
  the route is `PlotIconSuite`/`IconServicesLib` interception, and
  `_IconDispatch` (`$ABC9`) is selector-dispatched exactly like the trap
  we just patched — so it is now a small experiment, not research
  (plan 015 G4).
- **Nothing here has touched metal.** Every measurement is mac99 under
  QEMU. The PowerBook has seen none of this plane.
- **The live app has never been watched composing.** Everything is
  proven through fixtures and harnesses (015 G2 is that slice).
- **Plan 016 is mostly unstarted**: the accent ramps landed, but the
  metric and colour QUERY applet (`GetThemeMetric`,
  `GetThemeBrushAsColor`, ~40 selectors) has not been built. Its first
  deliverable is a DIFFERENCE LIST, and the stop condition is real — if
  the measured values match the ported ones, say so and stop.

- **The fidelity sweep's A/B was never taken.** The sweep is a baseline
  measured before the asset pack's effects, and the after-picture — the
  same rubric against a pack-enabled build, now that types reach the
  atlas as types and the 914 icons can actually resolve — has not been
  run. It is cheap and it is the honest test of whether the pack did
  anything a person can see.
