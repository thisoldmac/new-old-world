## What works now that did not this morning

- **Interiors compose.** A window's real content — text at true pens,
  primitives, list rows — is captured from the offscreen world that built
  it and re-homed into the window. Finder icon/list/button views, Date &
  Time, Memory, NOW's own Workshop, Sherlock 2.
- **Worlds are hooked at BIRTH**, by a resident 68K patch on the
  QDExtensions trap (`$AB1D`), installed at the armed pass in the armed
  process's own context. This is what reaches applications whose worlds
  are created, drawn, blitted and disposed inside one event pass — the
  sight-then-chase route hooked 0 of 8 on Sherlock; the patch reports
  77 born / 77 died / 0 missed.
- **The Appearance path is the big one.** Date & Time imports no
  `NewGWorld` at all, yet reports 286 worlds born — AppearanceLib creates
  them on its behalf, and the patch catches the TRAP regardless of
  caller. Any Appearance-themed application is therefore reachable,
  which is most of Mac OS 9's own interface.
- **The join nests.** Sherlock composites two levels deep (list → interior
  world → window), and destination port ORIGINS are part of the
  translation.
- **Assets are extracted offline**, 914 per-app icons and 127 system
  icons, with Platinum's 21 accent ramps measured from the theme file.
- **Desktop items survive**, roster failures name the guest's own reason,
  and MirrorKit's suite is in the gate.

## The lesson that outranks the features

**Every real defect found today was invisible to a green test suite and
visible the moment something was compared against the machine.**

- A QuickDraw clip is port-local and moves with the origin; the replay
  froze clips into fixed host-space rects. Fifteen of Sherlock's sixteen
  channel cells were in the stream, at correct coordinates, drawing
  nothing.
- The join ignored the destination's origin, so Sherlock's volume row
  rendered at the window's top-left instead of inside its list.
- `osaErr` was parsed, matched, and discarded one line before it could be
  reported — five different failures printed one sentence.
- Desktop items were read correctly by the guest and discarded by the
  host one poll later.
- Control panels rendered every themed field as "Bitmap unavailable",
  which was a false claim of missing data.

Our tests assert WHICH facts crossed. They were blind to WHERE things
landed and WHY things failed. **Compare a render against a guest
screendump before believing it.** `panel-recapture.py`-derived tooling
takes both in one run; screendumps live beside the renders.

## Traps, each one paid for today

- **A busy anchor port makes `scripts/spin-up-ppc` REFUSE, and your wire
  listener is then answered by another session's guest.** That voided two
  findings. Verify ports free with `lsof` FIRST, and use
  `tools/gwprobe.py --expect-build auto`, which reads this checkout's
  build hash and refuses a foreign guest. The tells to watch for: an
  identical build stamp across two supposedly fresh boots, a `psn` from a
  previous run, an empty `/private/tmp/nowvm-*` with no `qemu.pid`.
- **A probe is not the app.** A python driver speaking `scene.request`
  directly never runs the host's icon enrichment, so it cannot show
  desktop items either way. A "reconfirmation" written from one was void
  as evidence — and happened to be true by luck, which is worse than
  being wrong loudly.
- **`HostMachineGuardTests` fails when anything else holds port 5250.**
  That is the guard working, not a regression. Verify with
  `swift test --skip HostMachineGuardTests`; never weaken it.
- **A fresh agent worktree has no `.env.lab`**, so `scripts/build-guests`
  skips silently and "test-all green" then EXCLUDES the guest
  cross-builds. Copy it from a sibling worktree if you touch guest code.
- **The ring is the limit under load.** ~12 KB/s into 64 KiB is ~5 s of
  headroom; a hooked Sherlock lost 114018 bytes in one settle and its
  interior text with it. A cycle now drains up to 12 pages while the
  guest reports `more`. If an application beats that, reopen the ring
  decision WITH numbers rather than tuning the knob.

## In flight at handoff — check these before starting anything

Three subagents were running, each on its own branch off this one:

1. **Fidelity sweep** — driving many control panels and applications,
   comparing each against a guest screendump, scoring against a stated
   rubric, producing `docs/fidelity-sweep-2026-08-06.md` with a RED
   list. Deliberately a **baseline** taken BEFORE the asset pack's
   effects, for an A/B afterwards; it must record which build it
   measured.
2. **Broken interiors** — 34 skipped INVERT ops (invert is how classic
   Mac draws selection, carets and pressed states, so the mirror shows
   an unselected version of every window) and 39 region ops drawn as
   bounding boxes (a CONTRACT gap: the guest never sends region data).
3. **File types** — `OSADoScript` renders in source form, so
   `file type of` arrives as `«class APPL»` and the host takes its first
   four characters. Every icon carries `type: "«cla"`. With a mangled
   type every one of the 914 pack lookups misses, so this small fix is
   what stands between the pack and real per-application icons.

Merge each from its branch; resolve `docs/open-issues.md` conflicts by
KEEPING BOTH sides (that file is corrected by appending).

## Known-open, with the evidence

- **Sherlock's `Custom…` popup and magnifier are absent**, unexplained.
  Agent 2 was asked to classify rather than fix.
- **No capture in the corpus has a selected list row.** Changing the
  selection colour altered no render, and forcing it to magenta as a
  control also altered nothing. Selection rendering is untested by
  anything we own.
- **Icon identity is unsolved.** Icons arrive as bits with no identity;
  the route is `PlotIconSuite`/`IconServicesLib` interception, and
  `_IconDispatch` (`$ABC9`) is selector-dispatched exactly like the trap
  we just patched — so it is now a small experiment, not research
  (plan 015 G4).
- **Nothing here has touched metal.** Every measurement is mac99 under
  QEMU. The PowerBook has seen none of this plane.
- **The live app has never been watched composing.** Everything is
  proven through fixtures and harnesses (015 G2 is that slice).
- **Plan 016 is mostly unstarted**: the accent ramps landed, but the
  metric and colour QUERY applet (`GetThemeMetric`,
  `GetThemeBrushAsColor`, ~40 selectors) has not been built. Its first
  deliverable is a DIFFERENCE LIST, and the stop condition is real — if
  the measured values match the ported ones, say so and stop.
