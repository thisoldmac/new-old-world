### Adjudication 5 — a delegated finding that did not survive checking

The docs sweep reported a load-bearing product defect: that
`SceneBuilder.normalizeWindows` ends with `windows.sort { $0.z < $1.z }`,

not quote: *"per-app z is real; cross-app global stacking is
reconstructed front-app-first. True global order needs the WindowList
cross-links — a source improvement, not a renderer change."*

**Recorded because it is the method working.** Sweep C published a
delegated table without verifying it and had to retract the whole thing.
This is the same shape caught one step earlier: a sub-agent read the
function and not its caller, produced a specific and plausible defect,

document repeats was re-checked here by hand.
