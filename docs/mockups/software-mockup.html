What the mock is for

Layout, decided

  • The Processes/Hardware split view — item list left, detail right — reused, so Software sits beside its siblings.
  • Domain popup above the list (not tabs); five domains don't earn tab chrome.
  • Detail pane is where the lazy vers read lands — version, full path, dates — on selection only.

Open question — pick before building

  • For a selected non-running extension / control panel, every action is disabled (see the Extensions domain). Is "nothing to do" right, or do these want a later verb — reveal in Finder, or an enable/disable toggle?
  • Duplicates are rows, told apart by the detail pane's path — no modal picker (that's the console's #n/-v).

Honest about the sweep

  • Sweeping shows text progress, never a determinate bar — PBCatSearch has no known total mid-sweep.
  • Rows stream in; Rescan → Stop; ~4 s cold on the 1400c (catsearch-measured).

This is an HTML approximation of the Platinum look for design review — not the renderer. The controls are all native-api-route on CarbonLib 1.6 (Data Browser included). Real fonts are Charcoal/Geneva as here; the guest draws them through the Appearance Manager. Verification of the built page is still metal, per the ledger.
