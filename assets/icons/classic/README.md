# The New Old World icon pack

The application icon — the compact Mac with the Finder face on its screen —
drawn as a classic Mac icon family. Added 2026-07-31.

The icons are **drawn at 32×32 and 16×16, not scaled down from the artwork**.
Downsampling a 512px render produces a dithered photograph of an icon; at these
sizes the Apple logo is three pixels and the nose is one step in a profile
line, so each size is laid out by hand on its own grid.

## What is here

| Path | What it is |
| --- | --- |
| `icons.py` | Draws the icons. One semantic grid per size feeds all three depths, so the shapes are identical across the family and only the ink changes. **This is the source of truth** — edit it, not the PNGs or the `.r`. |
| `rez.py` | Packs `png/` into `now-icons.r`, then decodes its own output back to pixels and fails if any plane does not round-trip. |
| `now-icons.r` | The generated resource family. Do not hand-edit. |
| `png/` | Rendered icons and their masks, one file per size and depth. |
| `reference/source-512.png` | The full-resolution artwork the geometry was measured from. |
| `reference/newoldworld-512-16bit.png` | The artwork at 16-bit (RGB555). Not part of the icon family — see "No 16-bit icon" below. |
| `reference/review-sheet.png` | Every icon at 4×, 2× and 1×, on light and dark. 1× is the honest test. |
| `reference/preview-32.png`, `preview-16.png` | One family each, magnified for pixel-level review. Regenerated by `icons.py`. |

## The family

All six resources are ID 128.

| Resource | Size | Depth | Bytes |
| --- | --- | --- | --- |
| `ICN#` | 32×32 | 1-bit + mask | 256 |
| `icl4` | 32×32 | 4-bit | 512 |
| `icl8` | 32×32 | 8-bit | 1024 |
| `ics#` | 16×16 | 1-bit + mask | 64 |
| `ics4` | 16×16 | 4-bit | 128 |
| `ics8` | 16×16 | 8-bit | 256 |

Colour icons carry no mask; the Finder clips them with the 1-bit mask, and
pixels outside the silhouette are index 0.

## How each depth is drawn

- **1-bit** is line art, not a quantisation — black outline, white case, and a
  grid-aligned 50% checker for the screen. Eyes and smile get a one-pixel
  white halo, because bare black on a 50% checker is invisible. At 16×16 the
  base is solid rather than checkered: a checker one row tall reads as dashes.
- **4-bit** is flat fills from the 16-entry clut. The case is **silver, not
  beige** — that palette has no beige, only a saturated brown and a tan, so
  silver is the honest choice and the one real 4-bit system icons made.
- **8-bit** keeps the same shapes with a three-band blue screen and a gray
  ramp giving the case a highlight and a shaded edge.

Every colour is an exact clut entry; `rez.py` fails rather than snapping a
near-miss to the nearest index.

## Two deliberate departures from the artwork

**The face profile is cut steeper than the original.** Measured from the
512px source, the profile runs nearly vertical — about one pixel of travel
across the whole screen once scaled. Reproduced faithfully it reads as a blue
rectangle beside a white one. At 32×32 the forehead steps 10→9→8→7, the nose
tips out to 6, and it steps back to 8 underneath.

**The 16×16 has no Apple logo.** Three pixels cannot spell an apple. A 2×2
block of four colours reads as the Windows flag; a centred stem over a 3-wide
body reads as a "T"; a split bottom reads as legs. The floppy slot and the
silhouette already say "compact Mac", so the logo is dropped — which is what
real `ics#` icons do at this size. The 32×32 keeps the full rainbow logo,
where a stem pixel plus two stripe rows fit.

## No 16-bit icon

There is no 16-bit classic icon resource. The family goes 1/4/8-bit and then
jumps to 32-bit ARGB (`it32`/`t8mk`, Mac OS 8.5+). The 16-bit rendering in
`reference/` is the artwork truncated to RGB555 — a screen-depth rendering
with nothing to live in, kept because it is what a Thousands-of-Colours screen
would show.

## Regenerating

```
python3 icons.py   # grids -> png/
python3 rez.py     # png/  -> now-icons.r, with round-trip verification
```

Both are pure Pillow + NumPy and touch nothing outside this directory.

## Status, and how to adopt it

**Nothing includes `now-icons.r` yet, and these icons have never been seen on
real hardware.** They are verified only as far as tooling can go: every plane
round-trips, and Rez compiles the file to exactly six resources byte-identical
to the generator's output.

Adopting the pack is a deliberate step, not a drop-in:

1. `now-guest-ppc/resources/app.r` **already defines its own placeholder
   `ICN#` (128) and `ics#` (128)** — the one-pixel frame design. Rez'ing both
   files together is a duplicate-resource error. Those two resources have to
   be deleted from `app.r` first.
2. Add `now-icons.r` to the PPC guest's resource list in
   `now-guest-ppc/CMakeLists.txt`, alongside `resources/app.r`.
3. Build, deploy, and **look at it on a real machine** before it lands on
   `main`. An icon is UI, and the Finder renders it at sizes and depths no
   emulator screenshot fully stands in for — particularly the 1-bit checker,
   whose read depends on the actual display.

The 68K guest (`now-guest-68k/now-guest-68k.r`) defines no icon at all today;
the same pack serves it if wanted, subject to the same swap.
